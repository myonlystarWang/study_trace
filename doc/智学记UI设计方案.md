# 「智学记」UI/UX 整体设计方案与实施路径

> 本文档基于产品定位与 UI 设计讨论整理，系统性规划「智学记」移动端产品的设计工作流、信息架构、核心页面体验原则及落地路线图。

## 一、 产品重新抽象与信息架构 (Information Architecture)

「智学记」本质上不是一个单纯的教务数据统计后台，而是一个**面向孩子与家长的家庭学习助手与复盘闭环系统**。核心模块拆解如下：

```text
智学记 (StudyTrace)
│
├── 1. 首页 / 学习驾驶舱 (今天)
│   ├── 问候与日期 (心理暗示与温和感)
│   ├── 今日作业进度 (完成率、待办任务卡片)
│   ├── 连续学习打卡激励 (Streak，天数徽章)
│   ├── 今日错题复习入口 (艾宾浩斯待复习题数 + 一键开始)
│   ├── 今日学习用时概览 (分学科时长)
│   └── 快速录入浮动入口 (+ 录入作业 / 错题)
│
├── 2. 作业模块 (Homework)
│   ├── 今日作业列表 (学科、任务名、预计用时、截止状态)
│   ├── 打卡确认与完成反馈
│   ├── 历史作业归档
│   └── 逾期与未完成提醒机制 (含微信通知)
│
├── 3. 错题模块 (Mistakes - 核心竞争力)
│   ├── 错题多维度筛选 (学科 / 知识点 / 掌握度 / 录入时间)
│   ├── 错题多模态录入 (拍照裁剪、文字输入、数学公式 LaTeX 识别、原图插图保留)
│   ├── 艾宾浩斯智能复习 (第 1、2、4、7、15 天遗忘曲线推题)
│   ├── 今日待复习专项流 (掌握 / 模糊 / 未掌握 反馈)
│   └── 批量选题与组卷篮 (+ 加入待组卷)
│
├── 4. 试卷与 A4 组卷 (Paper & Print)
│   ├── 已选错题编排 (题目排序、题型分类、分值设定)
│   ├── A4 试卷生成与排版 (答题留白、标准考卷版式、答案与解析附页)
│   ├── 浏览器原生打印 / PDF 导出 (`@page { size: A4 }`)
│   └── 组卷历史与再练习记录
│
├── 5. 学情与成绩统计 (Analytics & Scores)
│   ├── 周期学情看板 (日/周/月学习时长、作业完成率、错题消化率)
│   ├── 考试成绩档案 (单科成绩、历史浮动折线、丢分知识点聚集)
│   └── 薄弱知识点热力分析
│
├── 6. 激励与成就 (Achievements)
│   ├── 连续打卡里程碑勋章
│   ├── 错题歼灭战绩
│   └── 阶段学习证书与正向反馈
│
└── 7. 我的与系统设置 (Settings)
    ├── 身份切换 (学生模式 / 家长模式)
    ├── 学段与教材版本配置 (小学/初中、科目选择)
    ├── 微信公众号通知绑定与推送规则
    └── 数据导入导出与备份
```

## 二、 设计技术选型与协作工作流

### 2.1 工具矩阵与角色分工（非二选一）

| 工具 / 形式 | 推荐度 | 在「智学记」中的定位与职责 | 不推荐的用法 |
|---|:---:|---|---|
| **AI Design Agent** | ⭐⭐⭐⭐⭐ | 需求梳理、用户画像推演、UX 交互推演、批量视觉探索、Design System 规则草拟 | 直接让 Agent 一次性输出 20 个互不连贯的孤立最终稿 |
| **Figma** | ⭐⭐⭐⭐⭐ | **UI 设计源**：设计规范 (Design System)、高保真界面、矢量组件库、设计交付标准 | 无法真实模拟复杂的公式渲染和真实数据交互 |
| **HTML / React** | ⭐⭐⭐⭐⭐ | **高保真交互源**：在真实设备体验手感、公式/图片渲染、状态跳转验证、快速试错 | 忽略样式统一导致各个页面临时拼凑 CSS |
| **SVG** | ⭐⭐⭐ | 独立矢量资产：Icon 库、成就勋章、插画徽章、图表空状态插图 | 拿 SVG 拼整张复杂业务页面（维护成本灾难） |
| **CSS Print** | ⭐⭐⭐⭐⭐ | A4 试卷专业排版与打印预览输出 | 纯用图片导出导致打印字迹模糊 |

## 三、 核心设计原则 (Design Principles)

### 3.1 移动端优先 (Mobile First)
- **核心场景**：孩子/家长在手机或平板上操作：拿起手机拍照搜/录题、课桌前作业打卡、睡前复习 10 分钟错题。
- **基准尺寸**：统一按典型移动端比例（如 390×844 或 375×812）进行设计，底部常驻 5 项导航：`首页`、`作业`、`错题`、`数据`、`我的`。

### 3.2 首页设计：是「今天」，不是冷冰冰的「Dashboard」
- **传统后台通病**：满屏堆砌图表、数据指标、后台管理表格，让孩子产生强烈的应试压力和抗拒感。
- **「今天」设计哲学**：
  - 聚焦**即时行动**：“我今天还要完成什么？”
  - 明确**截止状态**与清晰反馈；
  - 正向反馈：突出的连续学习天数（🔥 12 天）、温和鼓励语言。

### 3.3 错题复习闭环：产品的第二生命线
从「错题记录」升级为「提分飞轮」：
```text
发现错题 → 拍照裁剪/公式识别 → 知识点归类 → 智能推入艾宾浩斯复习
   ↑                                                     │
   └──────── 重新掌握 / 移入已掌握 ←── 掌握度反馈 ───────┘
                                         │
                                         ▼ (未彻底掌握 / 考前复习)
                                     勾选加入组卷
                                         │
                                         ▼
                                   A4 试卷生成与打印
```

### 3.4 Design System First（规范先行）
在铺页面之前，先固化设计原子：
- **Color Palette**：
  - Primary（主色）：清爽克制的蓝青色（如 `#2563EB` / `#0284C7`），兼具学习专业感与呼吸感；
  - Accent / Warm（强调色）：活力橙/暖黄（如 `#F59E0B`），用于连续打卡、徽章、重点提醒；
  - Functional（功能色）：成功绿（`#10B981`）、警示黄（`#FBBF24`）、错误红（`#EF4444`）；
  - Neutral（中性色）：浅灰背景（`#F8FAFC`）、卡片纯白（`#FFFFFF`）、分级文本（`#0F172A`, `#475569`, `#94A3B8`）。
- **Typography**：中文字体选用系统级 PingFang SC / MiSans / Inter 字体栈，层级清晰（Display, H1~H3, Body, Caption）。
- **Cards & Shadows**：统一采用大圆角（`16px` / `20px`）、大留白、柔和弥散阴影（Soft Elevation），拒绝生硬描边。

## 四、 核心页面设计与视觉 Prompt 参考

### 4.1 视觉探索 Prompt（可直接用于 Midjourney / 图像生成工具）

```text
设计一张高保真移动端 App UI 视觉稿，展示同一个教育学习 App「智学记」的两个并排手机页面，整体中文界面，现代、克制、清爽、有品质感，面向中小学生及家长，非幼稚卡通风。浅色纯净背景、大面积呼吸感留白、柔和圆角卡片、细腻层级与适度蓝绿色主色+暖色强调。无外部手机壳、无浏览器边框。

左侧页面（首页「今天」）：
- 顶部问候：“晚上好，今天也要加油”与日期；
- 今日进度卡片：“今日完成 3/5 (60%)”；
- 今日作业清单：学科标签（数学、语文、英语）、任务标题、预计用时、状态勾选；
- 激励卡片：“连续学习 12 天”微质感徽章；
- 今日复习卡片：“还有 6 道错题待复习”及“开始复习”主按钮；
- 底部常驻 5 项导航：首页（高亮）、作业、错题、数据、我的。

右侧页面（错题与复习「错题」）：
- 顶部标题与快速搜索框；
- 分科筛选 Tabs（全部、数学、语文、英语）；
- “今日艾宾浩斯复习”专属横幅（6 道待攻克）；
- 错题卡片流：题目区域预览图/LaTeX 公式占位、知识点 Tag（如「一元二次方程」）、错误原因（如「计算失误」）、上次复习日期与今日状态、掌握度环形进度；
- 悬浮操作按钮：“＋ 拍照录入”；
- 页面底部操作栏：“批量组卷 (已选 0)”。
```

## 五、 四阶段落地实施规划

### 阶段一：产品定义与交互架构落地（当前阶段）
- [x] 梳理产品全功能树与信息架构；
- [x] 确立移动端优先（Mobile First）交互原则；
- [ ] 制定底层数据模型对应关系（Homework、Mistake、ReviewLog、ExamScore、Paper）。

### 阶段二：Design System 建立
- [ ] 确立 CSS 变量与设计令牌（Colors, Shadows, Radius, Spacing, Typography）；
- [ ] 提取并封装高频组件：`TaskCard`、`MistakeCard`、`SubjectBadge`、`StreakBanner`、`BottomNav`、`FloatingActionButton`。

### 阶段三：先期攻坚 5 大核心主页面
1. **首页「今天」**：作业打卡、今日概览、连续天数、复习入口；
2. **作业管理页**：待办/已完成列表、状态切换、历史记录；
3. **错题库主页**：多维标签筛选、错题列表、加入组卷篮交互；
4. **艾宾浩斯每日复习页**：卡片翻转/刷题模式、掌握状态反馈；
5. **学情成绩页**：趋势折线图、单科成绩浮动列表。

### 阶段四：复杂能力与纸质化闭环
1. **错题多模态录入**：移动端拍照裁剪、图片压缩上传、OCR 与 LaTeX 公式转换；
2. **A4 一键智能组卷**：
   - 组卷参数配置（标题、副标题、排版留白密度、是否生成答案解析页）；
   - CSS Print 规则编写（`@page { size: A4; margin: 15mm; }`）；
   - 浏览器原生一键打印与导出 PDF。
3. **通知体系与多端打通**：微信服务号/公众号模板消息推送打通。
