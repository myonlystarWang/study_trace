## [v1.5.1] - 2026-09-06
### 服务热生效、移动端高度优化、错题角标修复与 AI 语音架构预留

#### 优化与修复 (Refinements & Fixes)
1. **学科修改 405 (Method Not Allowed) 彻底解决**：
   - 探明原因为后台单端口驻留进程未重启导致新路由未入内存；重启守护服务并彻底清理 `run.py` 与 `start.bat` 中 Windows 终端 GBK 转码乱码隐患，实测学科满分分值实时修改与保存 100% 成功。
2. **移动端垂直滚动条冗余高度修复**：
   - 根除各子页面 `min-height: 100vh` 叠加 `van-tabbar placeholder (50px)` 与冗余 `padding-bottom (84px)` 导致的必然纵向溢出缺陷。
   - `App.vue` 引入 `100dvh` 与弹性流式伸缩布局，各视图容器统一接入 `flex: 1` 与自适应内边距，页面在内容适中时整屏纯净显示、零冗余滚动条。
3. **错题本“今日复习”角标截断（三点省略号）修复**：
   - 废除在标签头文本流内手动混排内联角标的错误写法，改用 Vant 4 原生 `:badge` 属性与 `shrink` 紧凑模式；
   - 标题优化为“今日复习”，角标精准悬浮于右上角，手机窄屏下 100% 完整展现数字，彻底消除文字截断与 `...` 省略号。
4. **AI 语音与非结构化长文本智能解析分发体系架构预留**：
   - 在 `doc/development_plan.md`（第十二章）与 `doc/implementation_plan.md`（V2规划）中正式增设 AI 意图解析分发管道体系设计，涵盖输入采集（语音/文本）、STT 转写、LLM 意图与实体抽取、自动化业务接口分发与前端人机校验闭环。

## [v1.5.0] - 2026-09-06
### 家长管理精简重构、学科满分自适应与全站去重

#### 新增特性 (Features)
1. **学科满分灵活调整与自定义学科管理**：
   - 后端新增 `PUT /api/settings/subjects/{subject_id}` 接口，支持自由修改各学科的满分分值（如初中语数英按当地中考标准设定为 120 或 150 分，其他学科设为 100 分）。
   - 后端新增 `DELETE /api/settings/subjects/{subject_id}` 接口，支持安全删除家长新增的自定义拓展学科（如“科学”、“小语种”等）。
   - 核心系统学科安全守卫：预置核心 7 科（语数英道历地理生）的名称与删除权限受后端严格保护（返回 400 提示），杜绝误操作破坏数据完整性。
   - 前端集成“编辑学科”弹出窗，点击任意学科项即可直观调整满分分值或一键删除自定义学科。
2. **全站数据与入口去重**：
   - 移除家长管理视图中冗余的 A4 组卷历史卡片与成绩管理入口，避免与底部主导航（/paper 与 /scores）重叠，消除视觉杂乱与交互冗余。
   - 家长视图聚焦为清晰的 5 张纯净卡片：
     1. `推送提醒设置`
     2. `学科与满分管理`
     3. `月度打卡透视`
     4. `数据备份恢复`
     5. `安全口令与关于`

#### 优化与修复 (Refinements & Fixes)
- 顶部导航栏去除误导性的“返回”箭头，将标题精简为居中“家长管理”，作为底部第四个顶级 Tab 保持规范一致。
- 完善全套单元测试，在 `tests/test_m1_core.py` 中补充核心学科保护、满分修改与自定义学科增删的端到端测试。

## [v0.0.1] - 2026-09-05
### M0 工程基座初始化与工具链环境变量锁定

#### 基础设施与规范 (Infrastructure)
1. **工程骨架构建**：
   - 后端基于 FastAPI + SQLAlchemy + Pydantic v2 构建 RESTful API。
   - 采用 Alembic 进行生产级数据库迁移管理，严禁使用 `create_all` 等易产生技术债的捷径。
   - 前端基于 Vue 3 + Vite + Vant 4 构建移动优先轻量单页应用。
2. **Windows 环境与 PATH 守卫机制**：
   - 解决 Windows 系统环境变量 `Machine PATH > User PATH` 的反弹问题，锁定 Node 22 与 uv 优先激活机制。
3. **全自动化测试套件建立**：
   - 配置 pytest 与 FastAPI TestClient 自动化测试集，覆盖端到端全链路。
