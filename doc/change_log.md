## [v1.6.1] - 2026-09-06
### 打卡徽章语义修正、底部避让防截断、左滑编辑作业与「道法」别名贯通

#### 核心优化与修复 (Refinements & Fixes)
1. **打卡徽章状态与语义严密对齐**：
   - 探明当作业未全部勾选时此前错误显示了 `(✓) 今日打卡` 对勾图标造成已打卡假象；
   - 修正逻辑：只有当日所有作业 100% 勾选完成时才呈现满卡火苗徽章（`🔥 连打 X 天`）；未全部完成时展示中性进行中状态（`打卡中 X/Y` 或 `待打卡 X 项`），无作业时显示 `暂无作业`，彻底消除误解。
2. **作业列表底部避让与遮挡修复**：
   - 为 `.homework-cards` 容器注入 `padding-bottom: 84px` 避让空间，彻底防止最后一个作业卡片被底部的磨砂悬浮录入栏与 Tabbar 遮挡截断。
3. **作业卡片左滑支持「编辑」功能**：
   - 在左滑操作抽屉中新增橙色「编辑」按钮，点击呼出轻量级修改对话框，支持快速修改作业具体内容，后端 API 原生更新。
4. **学科重命名「道法」智能识别双向贯通**：
   - 升级 `QuickAddModal` 学科别名映射矩阵，支持 `道法`、`道德与法治`、`政治` 双向任意别名无缝互通匹配，无论系统预设还是自定义学科名称变更，均能 100% 自动归类。

## [v1.5.2] - 2026-09-06
### 推送卡片规范对齐、打卡指标基线修正与走势图离散点渲染

#### 优化与修复 (Refinements & Fixes)
1. **打卡出勤分析“全满卡天数”指标卡垂直对齐与基线统一**：
   - 探明中英文与字符（如 `100%`、`1 / 30` 与汉字 `1 天`）在未定高 flex item 下因行高与 baseline 差异导致第 3 个卡片下沉错位。
   - 统一使用弹性居中对齐容器 (`min-height: 64px; justify-content: center; align-items: center;`)，数值容器与标签容器固定像素高度 (`22px` 与 `16px`)，实现三个指标在水平中线与文字基线上的绝对齐平。
2. **每日作业打卡走势图孤立数据点显示与空图修复**：
   - 探明 ECharts 折线图配置了 `showSymbol: false`，当月仅有一两天打卡记录或存在非连续离散打卡时，折线无法连贯绘制，导致图表在视觉上“空无一物、点线皆无”。
   - 启用 `showSymbol: true`，指定实心圆点 (`symbolSize: 6`) 与主题白边描边 (`borderColor: #ffffff`)，确保单日打卡数据时清晰渲染关键圆点，多日数据时自然以曲线连接。
3. **推送提醒设置卡片图标修复、防换行与输入控件对齐**：
   - 修复图标丢失：将 Vant 4 不支持的 `bell-o` 替换为标准通知图标 `volume-o`，将 Server酱替换为合规消息图标 `comment-o`。
   - 渠道卡片标题与标签紧凑排版：各渠道卡片标题添加 `white-space: nowrap;` 杜绝折行，简化状态标签为单行（如 `iPhone 首选 · 免账号`、`企微/钉钉/飞书`）。
   - 输入框与测试按钮全局水平/垂直对齐：对所有渠道 `<van-field>` 注入固定 `label-width="70px"` 与 `center` 垂直居中，统一测试按钮尺寸 (`min-width: 52px; height: 28px`)，实现各行输入框左边缘与测试按钮右边缘的像素级对齐。
4. **PushPlus 提醒去噪与轻量化（遵循 iOS Caption 规范）**：
   - 彻底废除占用多行亮黄色底色的大面积 `<van-notice-bar>`；
   - 改为 iOS 风格的极简 11px 静默灰色辅助说明（`.channel-caption`），紧随 Token 输入框下方，页面视觉重心回归核心配置项，垂直高度大幅压缩。
5. **备份安全须知从常驻警告重构为“即时二次确认弹窗”**：
   - 彻底移除“数据备份恢复”卡片底部长达 5 行的常驻高饱和度红色警告条；
   - 将敏感凭证保护须知后置到用户实际点击【全站数据导出备份】的操作瞬间，调用阻断式确认弹窗（`showConfirmDialog`）进行即时安全告知，页面立减 80px 冗余高度，实现常驻界面的极致清爽与安全时机精准触达。
