# 家长管理页面（SettingsView）折叠卡片化重构方案

## 概述与背景
目前家长管理页面（[SettingsView.vue](file:///d:/工作/ww/personal_work/study_trace/frontend/src/views/SettingsView.vue)）解锁后将**推送渠道配置（含多成员详情）、9 门学科列表、2 个 ECharts 大图表、数据备份、OCR 引擎设置、安全口令**等 6 大模块全部直接纵向平铺展开。在手机端需要上下滑动 5~6 屏，视觉负荷极重，寻找特定功能不便。

根据对齐的 **方案 A（分组折叠卡片模式）**，我们将页面重构为：**「首屏常驻核心出勤指标概览 + 6 大模块按需折叠卡片」**，每个卡片头部常驻显示当前配置摘要，点击平滑展开对应设置项。

---

## 拟实施的具体改造

### 1. 结构与视觉重构
- **顶部常驻区**：
  - 家长空间顶部通知条
  - **月度出勤核心指标仪表盘**（月均打卡率、有效出勤天数、全满卡天数、月份步进器）+ 「一键发送今日汇总」快捷动作
- **分组折叠卡片（默认全部收起，一屏尽收眼底）**：
  1. 🔔 **推送提醒设置**：
     - *头部摘要*：动态显示 `已启用 微信测试号(2人)、Bark 等 2 个渠道` 或 `未启用渠道`
     - *展开内容*：渠道网格多选、微信多成员表格、Server酱/Bark/Webhook 配置与即时测试、保存配置
  2. 📚 **学科与满分管理**：
     - *头部摘要*：动态显示 `已配置 X 门学科 (含语数英等)`
     - *展开内容*：学科分值 Cell 列表与新增自定义学科入口
  3. 📊 **出勤深度图表分析**：
     - *头部摘要*：显示 `每日走势图与缺卡频次分布`
     - *展开内容*：双轴混合走势折线/柱状图 + 科目缺卡频次分布柱状图
     - *性能优化*：展开时才动态触发 ECharts 的初始化与 `resize()`，避免隐藏状态下宽高为 0 的渲染缺陷
  4. 📷 **OCR 识别引擎设置**：
     - *头部摘要*：动态显示 `智谱 GLM-4V-Flash (已激活)` 或 `RapidOCR (本地离线)`
     - *展开内容*：推理引擎说明、API Key 输入框、保存与恢复纯本地离线按钮
  5. 🛡️ **数据备份与还原**：
     - *头部摘要*：显示 `全站 SQLite 数据库与错题图备份`
     - *展开内容*：全站数据导出 Zip 下载、Zip 包导入还原
  6. ⚙️ **安全口令与系统**：
     - *头部摘要*：显示 `管理口令、系统自检与退出锁定`
     - *展开内容*：修改 PIN 口令、进入系统关于页面、退出家长模式并锁定

### 2. 交互逻辑与状态管理
- 增加 `activeSections` 响应式数组，支持独立展开/收起任意卡片。
- 支持平滑过渡 CSS 动画与箭头的 180° 旋转效果。
- 监听「图表分析」卡片的展开事件，自动执行 `nextTick` 配合 `echarts.resize()` 确保高清渲染无形变。

### 1. 界面与交互验证
- 解锁家长管理模式后，检查首屏是否控制在 1~2 屏以内，所有 6 个折叠卡片头部是否正确显示当前状态摘要。
- 依次点击各个卡片头部，验证展开和收起动画是否流畅自然，箭头旋转是否正常。
- 重点验证「出勤深度图表分析」展开后，走势图和科目分布图是否能正确撑满宽度并正常交互。

- 启动服务并在浏览器访问 `http://127.0.0.1:28000` 进行端到端走查。
